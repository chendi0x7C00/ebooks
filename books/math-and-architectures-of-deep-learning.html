Math and Architectures of Deep Learning · a condensation

The mathematics that makes deep learning work

A model changes coordinates. A loss says what matters. A gradient connects the two. Follow that argument from a straight line to a variational autoencoder.

Based on Krishnendu Chaudhury’s bookAbout 60 minutes, including six small experiments

On a small screen, swipe wide diagrams sideways. Every experiment also reports its result in text.

A neural network can look like a collection of unrelated techniques: matrix multiplication, probability distributions, nonlinear functions, optimizers, convolutional blocks. Their connection is more useful than their names. We choose a family of functions, express a preference for some outputs over others, and differentiate the resulting objective with respect to the numbers that define the function. Architecture determines which functions are easy to represent; statistics determines which fit we should trust.

This article condenses Math and Architectures of Deep Learning (Manning, 2024), by Krishnendu Chaudhury with Ananya H. Ashok, Sujay Narumanchi, and Devashish Shankar. It preserves the mathematical path through all fourteen chapters while omitting exhaustive proofs, repeated examples, and full application implementations. The order follows dependencies rather than the table of contents. Everything here assumes school algebra and a willingness to read a few derivatives; each new mathematical object gets a job before it gets a formula.

01 · The problem we are actually solving

Learning means choosing a function from examples

Book: chapter 1, pp. 1–17; chapter 3, pp. 83–89.

Suppose an input x contains an object’s hardness and sharpness. We want a threat score. A possible model is fθ(x) = w₁x₁ + w₂x₂ + b, where the adjustable parameters are θ = (w₁,w₂,b). Larger weights make a feature matter more; the bias sets the baseline. Thresholding the score produces a decision. A house-price estimator has the same mathematical form, even though the output means something different.

The unknown target is rarely available as a formula. Instead, supervised learning gives us a dataset D = {(xi,yi)}i=1n. The architecture specifies the allowable functions. Training chooses parameters by minimizing a loss averaged over those examples:

J(θ) = 1/n ∑i=1n ℓ(fθ(xi), yi) + λR(θ)Empirical risk measures training fit. The optional regularizer R encodes a preference among possible fits.

The loss is a design choice with statistical consequences. Squared error penalizes numerical discrepancies. Cross entropy penalizes assigning low probability to the observed label. A regularizer might discourage large weights. The coefficient λ controls the tradeoff, but its numerical meaning depends on whether the data loss is summed or averaged. Keep that normalization consistent when comparing implementations.

Training and inference answer different questions. During training, labels and derivatives help change the parameters. During inference, the fitted parameters are held fixed and the model evaluates a new input. Some layers also change behavior between these phases, so inference is more than removing the optimizer. We will return to dropout and normalization when discussing a complete training loop.

There is also a deeper difference between fitting the observed sample and solving the intended task. The quantity we want is the expected loss on future examples, E(X,Y)∼P[ℓ(fθ(X),Y)]. We only observe a finite sample from some distribution P. A flexible function can memorize that sample while making arbitrary predictions elsewhere. Generalization depends on the data, model restrictions, optimization, and the relationship between training conditions and deployment.

For that reason, split data before learning preprocessing statistics, tuning hyperparameters, or fitting the model. A validation set guides those choices; a held-out test set estimates final performance. If adjacent video frames or repeated measurements from one person cross the split, apparent success can reflect leakage. No amount of elegant calculus repairs an evaluation that accidentally reveals the answer.

Geometry makes these ideas concrete. An input is a point in feature space. A binary classifier divides that space into regions. With score s(x) = wᵀx + b, the zero-score boundary is a hyperplane. A nonlinear network can bend the boundary, or transform the coordinates until a simple final boundary is enough. Regression instead assigns a numerical value across the same space. Classification can be built from such scores, but a score alone is not automatically a calibrated probability.

This view immediately exposes a limitation: applying a sigmoid to a single affine score changes the output range, but thresholding at 0.5 still yields the same hyperplane. A nonlinear output function does not, by itself, create an arbitrarily shaped classification boundary. To obtain richer geometry we need nonlinear features or compositions of layers. First, though, we need a language for coordinates, distances, and transformations.

02 · Give arrays a geometric meaning

Vectors measure agreement; matrices move space

Book: chapter 2, pp. 18–82; chapter 4, pp. 118–123.

Throughout this article, an individual vector is a column: x ∈ ℝd. A layer with d inputs and m outputs uses W ∈ ℝm×d and b ∈ ℝm, so Wx + b ∈ ℝm. For a dataset, we place observations in rows: X ∈ ℝn×d. Thus a batch layer computes XWᵀ + 1bᵀ. Checking these dimensions catches many mistakes before code runs.

The dot product aᵀb = ∑jajbj measures alignment while also depending on length. Its geometric form is ‖a‖₂‖b‖₂ cos θ, where ‖x‖₂ = √(∑jxj²). Orthogonal vectors have zero dot product. Dividing by both lengths gives cosine similarity, useful when direction matters more than magnitude. It is undefined for a zero vector; an implementation must handle that case explicitly.

A classifier’s weight vector points perpendicular to its boundary. Moving along the boundary leaves the score unchanged; moving along the normal changes it fastest. The signed Euclidean distance to wᵀx + b = 0 is (wᵀx + b)/‖w‖₂, assuming nonzero w. This explains why multiplying both weights and bias by a positive number preserves the boundary while changing the raw scores.

A matrix is a linear transformation because it preserves sums and scalar multiplication: A(αx + βy) = αAx + βAy. Adding a bias gives an affine transformation, which need not preserve the origin. Libraries often call affine modules “linear layers”; the distinction matters when reasoning about composition or subspaces. A tensor, in deep-learning code, is usually a multidimensional array. Its axes might mean batch, channel, height, and width; those meanings matter as much as its numerical entries.

The columns of A show where the coordinate basis vectors go. Their span is the set of reachable outputs. The rank is the dimension of that span. A square d × d matrix has an inverse exactly when its rank is d. If two columns carry redundant information, the transformation loses a direction and cannot be undone uniquely. Rectangular matrices can preserve information on some subspaces, but do not have ordinary two-sided inverses.

This becomes a learning problem in least squares. For a linear predictor with design matrix X and target vector y, we minimize ½‖Xw − y‖₂². Differentiating gives Xᵀ(Xw − y) = 0. Thus the residual is orthogonal to every column of X: the prediction is the orthogonal projection of y onto the space of possible predictions. If X has full column rank, the familiar solution is (XᵀX)−1Xᵀy.

That formula is a derivation, not a recommendation to form the inverse numerically. QR or SVD solvers are preferable, particularly when columns are nearly dependent. The Moore–Penrose pseudoinverse gives w* = X⁺y even when the system has no exact solution or many exact solutions; among least-squares solutions it chooses the one with minimum Euclidean norm. Tiny singular values still amplify noise. The condition number κ = σmax/σmin, restricted to an invertible setting, quantifies this sensitivity. A determinant’s magnitude alone is not a reliable conditioning diagnostic.

Eigenvectors describe directions a square transformation only scales, possibly reversing their orientation: Av = λv. A real symmetric matrix has an orthonormal eigenbasis, so A = QΛQᵀ. This is especially useful for quadratic forms xᵀAx: in coordinates u = Qᵀx, they become ∑jλjuj². Positive semidefinite means every λ is nonnegative; positive definite means every λ is positive. The former allows flat directions, while the latter gives a strictly curved bowl. The same decomposition will explain both variance in data and stability in optimization.

03 · A representation before neural networks

PCA keeps the directions that carry variation

Book: chapter 4, pp. 115–148; chapter 14, pp. 474–481.

An image may contain thousands of pixel coordinates, yet its meaningful variation may come from a much smaller set of causes. Principal component analysis asks a restricted but powerful question: which linear directions retain the most variation? Center the dataset by subtracting the training mean μ = (1/n)∑ixi from every observation. Let X now denote this centered n × d matrix. We use population-style empirical covariance C = XᵀX/n; the alternative sample convention divides by n − 1. It changes eigenvalues by a common factor, not principal directions.

Project each point onto a unit vector v. The resulting scalar is ti = vᵀxi. Its mean is zero, and its variance is (1/n)∑iti² = vᵀCv. The unit-length constraint prevents us from inflating variance merely by scaling v. Use a multiplier λ to maximize vᵀCv − λ(vᵀv − 1). Its derivative vanishes when:

2Cv − 2λv = 0  ⇒  Cv = λvAt a unit eigenvector, projected variance equals its eigenvalue. Choose the largest eigenvalue first.

Subsequent directions maximize remaining variance subject to orthogonality. If Vk ∈ ℝd×k holds the first k eigenvectors, the reduced data is Z = XVk ∈ ℝn×k. Reconstruction is X̂ = ZVkᵀ, followed by adding the mean back. The coordinates change, but this projection has a precise objective: among k-dimensional linear subspaces, it minimizes total squared reconstruction error.

SVD reaches the same result without explicitly constructing C. For centered X ∈ ℝn×d, a thin decomposition is X = UΣVᵀ, with r nonzero singular values, U ∈ ℝn×r, Σ ∈ ℝr×r, and V ∈ ℝd×r. The columns of U and V are orthonormal. Each rank-one term σjujvjᵀ contributes one independent pattern. Since XᵀX = VΣ²Vᵀ, the principal directions are columns of V and the covariance eigenvalues are σj²/n. Singular values are their square roots after restoring the normalization, not the eigenvalues themselves.

Keeping the largest k singular values yields the best rank-k approximation Xk = UkΣkVkᵀ. Its squared Frobenius error is ‖X − Xk‖F² = ∑j>kσj²; the spectral-norm error is the next singular value. These statements turn dimensionality reduction into a measurable approximation. With singular values 6, 3, and 1, retaining two components leaves squared reconstruction error 1 and keeps 45/46 of the squared Frobenius energy.

The pseudoinverse also falls out of SVD: X⁺ = VΣ⁺Uᵀ, where positive singular values are reciprocated. Truncating very small singular values stabilizes a solve by discarding poorly identified directions. Ridge regression takes a smoother approach: it replaces reciprocal scaling 1/σ with σ/(σ² + λ) for an objective using ‖Xw−y‖² + λ‖w‖². Representation and regularization are already connected before we introduce a neural network.

The book applies this geometry to document retrieval. A document becomes a sparse vector of term-frequency values multiplied by inverse document frequency, for example idf(t) = log(N/df(t)) for a corpus of N documents. Common terms receive less weight. Cosine similarity compares directions of document and query vectors. A zero score means no overlap in these coordinates, which may miss a real relationship expressed with different words.

Latent semantic analysis uses truncated SVD of a document–term matrix A to discover shared linear patterns. With A ≈ UkΣkVkᵀ, document coordinates can be AVk = UkΣk, and a row-shaped query maps to qᵀVk. Unlike ordinary PCA, classical LSA commonly leaves this sparse term matrix uncentered; its directions then describe energy rather than centered variance. SVD factors are not guaranteed to be human-readable topics or modern semantic understanding. They expose co-occurrence structure under a linear approximation.

Two cautions remain. Large variance is not necessarily useful for prediction: a background feature may vary much more than the label-bearing detail. And a curved one-dimensional structure may require several principal components. Feature scaling also matters, because changing units changes variance. PCA is an optimal answer to a specific geometric question, not an automatic definition of importance.

04 · Say what a prediction means

Probability separates uncertainty from geometry

Book: chapter 5, pp. 149–192; chapter 6, pp. 193–212.

A point describes one observation. A distribution describes how observations vary. For discrete variables, the joint probability p(x,y) describes a pair; summing over y gives the marginal p(x) = ∑yp(x,y). Conditioning restricts attention to observations satisfying a known event: p(y|x) = p(x,y)/p(x), provided the denominator is positive. The same joint can be factored in either order, which gives Bayes’ rule:

p(y|x) = p(x|y)p(y) / p(x)Posterior = likelihood × prior / evidence. The denominator sums or integrates the numerator over possible y.

For a concrete synthetic example, suppose a component is defective with prior probability 0.1. A flag occurs with probability 0.8 for defective components and 0.2 for good ones. The flag’s marginal probability is 0.8×0.1 + 0.2×0.9 = 0.26. A flagged component is defective with probability 0.08/0.26 ≈ 0.308. The likelihood of a flag given a defect, 0.8, is a different quantity from the probability of a defect given a flag. The prior prevalence is part of the inference.

For continuous variables, a density p(x) replaces point probabilities. Integrating the density over a region gives its probability. A density can exceed one: a uniform distribution on an interval of length 0.1 has density 10. Its total integral is still one, and the probability of any exact point is zero. This distinction matters whenever a neural network predicts a distribution over real-valued outputs.

Expectation is a weighted average: E[g(X)] = ∑xp(x)g(x), or the corresponding integral. Variance is E[(X−μ)²]. Covariance E[(X−μX)(Y−μY)] measures linear co-variation. For a vector, the covariance matrix collects all pairwise covariances and is positive semidefinite because vᵀCv is the variance of a projection. Thus the covariance geometry used in PCA has a probabilistic interpretation.

Independence is stronger than zero covariance. Independence means p(x,y)=p(x)p(y), so learning X tells us nothing about Y. If X is uniform on [−1,1] and Y=X², covariance is zero by symmetry, yet Y is determined by X. Orthogonality between two particular feature vectors is not a declaration of statistical independence either. These statements live at different levels: one concerns vectors, another concerns distributions.

Three distribution families will do much of our work. A Bernoulli variable has values 0 and 1, with p(y)=πy(1−π)1−y. A categorical variable chooses one of K outcomes with probabilities summing to one; a one-hot vector records that choice. Binomial and multinomial variables count repeated independent Bernoulli or categorical outcomes. A multivariate Gaussian describes a real vector using mean μ and positive-definite covariance Σ:

p(x) = exp[−½(x−μ)ᵀΣ−1(x−μ)] / √((2π)d det Σ)

The quadratic in the exponent measures distance after accounting for scale and correlation. Its constant-density contours are ellipsoids aligned with covariance eigenvectors. A Gaussian is therefore not just a familiar bell curve: it joins linear algebra to a model of uncertainty. We will write 𝒩(μ,σ²) with the second argument explicitly meaning variance.

Information theory converts a probability into a penalty. The surprise of an outcome is −log p(x); entropy averages that surprise under the same distribution. We use natural logarithms, so the unit is a nat. For categorical distributions:

H(p) = −∑x p(x) log p(x)H(p,q) = −∑x p(x) log q(x)DKL(p‖q) = ∑x p(x) log[p(x)/q(x)] = H(p,q) − H(p)

KL divergence is nonnegative and zero when the distributions agree almost everywhere, but it is asymmetric and is not a distance metric. If p assigns positive mass where q assigns zero, DKL(p‖q) is infinite. Reversing the arguments changes which distribution supplies the average, so it changes the penalty. Continuous versions use integrals; differential entropy can be negative and depends on coordinates, while KL retains its nonnegativity. Conditional entropy averages uncertainty after observing another variable. The identity H(X,Y)=H(X)+H(Y|X) is the information counterpart of factoring a joint probability.

These definitions explain why a probabilistic prediction can be trained with a numerical objective. To see which objective, we must specify the statistical model rather than select a loss by habit.

05 · Assumptions become an objective

Likelihood turns a model of the world into a loss

Book: chapter 6, pp. 212–238; chapter 9, pp. 300–315.

Maximum likelihood estimation chooses parameters under which the observed data has high probability density or mass. For independent observations conditional on θ, the likelihood is p(D|θ)=∏ip(yi|xi,θ). It is a function of θ with data held fixed. Taking logarithms turns products into sums; minimizing the negative log-likelihood gives a training loss. This does not mean the fitted model is probably true. It means the observations fit one parameter setting better than alternatives within the chosen family.

For regression, assume Y|x,θ ∼ 𝒩(fθ(x),σ²) with known, constant variance. One observation contributes (y−fθ(x))²/(2σ²) + ½log(2πσ²). Constants do not affect the optimum for θ, so maximum likelihood becomes least squares. If the noise scale depends on the input and is learned, the logarithmic variance term can no longer be dropped. A network that reports uncertainty must be penalized for making every distribution arbitrarily broad.

For categorical classification, the network produces logits s, converted by softmax to qk=exp(sk)/∑jexp(sj). The likelihood of observed class c is qc, hence loss −log qc. With a one-hot target y, this is −∑kyklog qk. Differentiating with respect to logits gives the particularly useful result ∂ℓ/∂s = q − y. We get both a statistical interpretation and a simple backward signal.

Maximum a posteriori estimation adds a prior: p(θ|D) ∝ p(D|θ)p(θ). Taking negative logarithms gives the data loss plus −log p(θ). A zero-mean Gaussian prior yields a squared L2 penalty; independent Laplace priors yield L1. MAP still returns one parameter setting, the posterior mode. It does not retain the full posterior uncertainty, and a prior need not always prefer small magnitudes: that depends on the prior we choose.

Latent variables introduce another level. Suppose a dataset combines two or more populations, but we do not observe which population produced each point. A Gaussian mixture model introduces a discrete latent label Z:

p(x) = ∑k=1K πk 𝒩(x; μk, Σk)rik = p(Zi=k|xi) = πk𝒩(xi; μk,Σk) / ∑jπj𝒩(xi; μj,Σj)πk ≥ 0 and ∑k πk = 1. A responsibility is a posterior probability, not a hard assignment.

The log-likelihood contains a logarithm of a sum, so the simple Gaussian sample-mean solution no longer applies directly. Expectation–maximization alternates two tractable steps. The E-step computes responsibilities using current parameters. The M-step treats those responsibilities as weights and refits each component. With Nk=∑irik, the updates are πk=Nk/n, μk=∑irikxi/Nk, and a similarly weighted covariance around the new mean.

Why does this help? For any distribution q over the latent label, Jensen’s inequality gives a lower bound on the log marginal likelihood. Choosing q equal to the current posterior makes the bound tight; maximizing it with respect to model parameters improves or preserves likelihood when the steps are exact. This is the same variational logic we will use for autoencoders. In a mixture, however, the posterior over a finite label is directly computable.

EM does not guarantee the global optimum. Initialization matters, label names can be permuted without changing the model, and unconstrained Gaussian mixtures have a more serious pathology: one component can collapse onto a single point with covariance approaching zero, making likelihood unbounded. Covariance floors or suitable priors address this. A larger likelihood is only meaningful within a model and a valid fitting procedure; it is not a substitute for checking generalization.

The machinery now has two complementary interpretations. Geometry describes transformations of points. Probability describes distributions over possible observations and hidden causes. A neural network can supply the flexible function inside either interpretation.

06 · Build functions by composition

Nonlinearity lets simple pieces make complex regions

Book: chapter 7, pp. 239–271; chapter 8, pp. 272–280.

A perceptron computes h(x)=H(wᵀx+b), where H(t) is one for t ≥ 0 and zero otherwise. It asks which side of a hyperplane the input occupies. Appropriate weights implement Boolean AND or OR. But one hyperplane cannot implement XOR: (0,0) and (1,1) must be negative, while (1,0) and (0,1) must be positive. The diagonals joining the two classes intersect, so no straight separator can put each pair on its required side.

A hidden layer resolves the problem by changing the representation. Let s=x₁+x₂. One hidden unit asks whether at least one bit is on; another asks whether both are on. The output keeps the first condition and excludes the second:

h₁ = H(x₁+x₂−0.5),   h₂ = H(x₁+x₂−1.5)ŷ = H(h₁−h₂−0.5)

For the four inputs in order (0,0), (1,0), (0,1), (1,1), the hidden pairs are (0,0), (1,0), (1,0), and (1,1); the outputs are 0, 1, 1, and 0. Two separate input points are intentionally given the same hidden code. This representation is useful precisely because it discards distinctions irrelevant to the answer. A neural network need not preserve all information or be invertible.

Step functions make the logic visible but are poor tools for gradient training: their derivatives are zero away from the threshold and undefined at it. A sigmoid σ(t)=1/(1+e−t) is smooth, with derivative σ(t)(1−σ(t)). Tanh is zero-centered but also saturates. ReLU, max(0,t), is piecewise linear and has derivative one for positive inputs and zero for negative inputs; a chosen subgradient handles zero. ReLU networks can still be nonlinear because the active linear region depends on the input.

Nonlinearity between layers is essential. Two affine maps collapse: W₂(W₁x+b₁)+b₂ = (W₂W₁)x + W₂b₁ + b₂. Repeating them adds parameters but no new class of input–output functions, apart from rank restrictions introduced by narrow intermediate layers. Insert a nonlinear activation and the collapse generally fails. Successive layers can then construct edges from pixels, shapes from edges, and task-relevant features from shapes, although such interpretations must be checked rather than presumed for every unit.

The universal approximation theorem formalizes a part of this expressive power. One classical version says that finite sums of suitably weighted sigmoid units can approximate any continuous function on a compact domain to any desired uniform accuracy, given enough hidden units and a linear output combination. The assumptions and approximation norm matter. A continuous network cannot uniformly approximate an actual jump discontinuity arbitrarily well across the jump, although other approximation notions can handle discontinuous targets.

This is an existence theorem. It does not promise a small network, an efficient algorithm for finding the weights, or reliable predictions outside the domain covered by data. Depth matters because compositions can represent some structured functions much more economically than a shallow expansion. It also imposes a useful architectural preference: the function is built through intermediate computations rather than an unrestricted table of answers.

Expressivity therefore creates a new problem as it solves the old one. We now have enough flexibility to fit complex data, but the parameters may number in the millions and the objective is usually nonconvex. The next question is computational: how do we determine which of those parameters should change?

07 · Follow responsibility backward

Backpropagation is the chain rule with shared work

Book: chapter 3, pp. 89–114; chapter 8, pp. 280–299.

A derivative answers a local counterfactual: if this number changed a little, how would the result change? For a scalar objective J with parameter vector θ, its gradient collects those sensitivities. A first-order Taylor approximation is J(θ+Δ) ≈ J(θ)+∇J(θ)ᵀΔ. Among steps of fixed Euclidean length, Cauchy–Schwarz says the most negative first-order change occurs opposite the gradient. This justifies θ ← θ−η∇J(θ) for learning rate η. “Steepest” depends on the norm used to measure the step.

The approximation is local. Curvature enters through the Hessian H, the matrix of second derivatives: J(θ+Δ) ≈ J(θ)+∇JᵀΔ+½ΔᵀHΔ. On a quadratic with positive eigenvalue λ, the error along its eigenvector is multiplied each gradient step by 1−ηλ. Stability requires |1−ηλ|<1, or 0<η<2/λ. One large-curvature direction can therefore limit the rate of progress along every other direction.

A convex objective obeys J(tθ+(1−t)ϕ) ≤ tJ(θ)+(1−t)J(ϕ) for t in [0,1]. A local minimum is then global; a positive-semidefinite Hessian characterizes convexity for twice-differentiable functions on an open convex domain. Neural-network objectives generally lack this property. A zero gradient can indicate a minimum, a maximum, a saddle, or a flat region. Backpropagation computes derivatives efficiently; it does not certify what optimization will find.

Now separate the network into layers. With a⁰=x, layer ℓ computes zℓ=Wℓaℓ−1+bℓ and aℓ=φℓ(zℓ). If the previous width is dℓ−1 and the current width is dℓ, then Wℓ has shape dℓ×dℓ−1. The Jacobian of a vector-valued function from d inputs to m outputs is m × d, with entry ∂fi/∂xj. A scalar loss’s column gradient travels backward through the transpose Jacobian.

Define δℓ=∂J/∂zℓ ∈ ℝdℓ. For elementwise activations, the entire backward pass is:

δL = (∂J/∂aL) ⊙ φ′L(zL)δℓ = ((Wℓ+1)ᵀδℓ+1) ⊙ φ′ℓ(zℓ)∂J/∂Wℓ = δℓ(aℓ−1)ᵀ,   ∂J/∂bℓ = δℓ⊙ means elementwise multiplication. The weight gradient is an outer product with the same shape as Wℓ. Average per-example gradients for a mean minibatch loss.

The first expression must be adapted for a non-elementwise output activation. In particular, softmax has a full Jacobian, but combining it with categorical cross entropy simplifies directly to δL=q−y for an affine logit layer. Treating softmax as independent scalar sigmoids gives the wrong derivative. This is one reason fused loss functions are convenient.

Reverse-mode automatic differentiation applies this logic to a computation graph. The forward pass saves needed intermediate values. The backward pass accumulates contributions from every downstream use, reusing each local derivative rather than differentiating the whole expression separately for every parameter. This makes the cost comparable to a small number of forward evaluations for a scalar loss, even with many parameters.

Compute every gradient using the parameter values from the same forward pass. Only then apply the optimizer update. If a later layer’s weights change before an earlier layer’s delta is formed, the backward pass no longer differentiates the function that produced the loss. Likewise, clear stored gradients before a new minibatch unless accumulation is intentional. These are computational details with mathematical meaning.

The compact code below is a complete illustrative regression loop, assuming PyTorch is installed. It learns a synthetic function rather than a benchmark. The important order is visible: forward, loss, clear gradients, backward, update. Validation runs with fixed weights and disabled gradient recording.

import torch
from torch import nn

torch.manual_seed(7)
X = torch.randn(256, 2)
y = X[:, :1].square() - 0.5 * X[:, 1:2]
Xtr, Xva, ytr, yva = X[:192], X[192:], y[:192], y[192:]
model = nn.Sequential(nn.Linear(2, 16), nn.Tanh(), nn.Linear(16, 1))
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(200):
    model.train()
    for ids in torch.randperm(len(Xtr)).split(32):
        prediction = model(Xtr[ids])             # [batch, 1]
        loss = (prediction - ytr[ids]).square().mean()
        optimizer.zero_grad(set_to_none=True)
        loss.backward()                         # all gradients first
        optimizer.step()                        # then change weights
    model.eval()
    with torch.inference_mode():
        validation_loss = (model(Xva) - yva).square().mean()
print(float(validation_loss))

Knowing how to differentiate a network is only half of training it. We still need to choose what errors count, how to combine noisy gradients, and what evidence will tell us to stop.

08 · The objective and the route to it

Training choices encode different kinds of preference

Book: chapter 9, pp. 300–342.

Start with the output’s meaning. Squared error is natural for a conditional mean under constant-variance Gaussian noise. Absolute error corresponds to Laplace noise and targets a conditional median. Binary cross entropy is −y log q−(1−y)log(1−q) for a Bernoulli output. Use one sigmoid per label for multilabel tasks where several labels can coexist; use softmax for a single mutually exclusive categorical choice.

Compute these losses from logits with numerically stable functions. For softmax cross entropy, ℓ=−sc+log∑jexp(sj); subtracting the maximum logit before exponentiating prevents overflow without changing probabilities. Binary cross entropy with logit s can be written max(s,0)−ys+log(1+exp(−|s|)). Taking a naive logarithm of a rounded probability near zero can turn a mathematically finite loss into an infinity.

Some losses express a different emphasis. Focal loss multiplies the correct-class log loss by (1−qt)γ, optionally with class weight αt. With γ = 0 it reduces to weighted cross entropy; larger γ reduces the influence of already-easy examples. Hinge loss, max(0,1−ys) for y∈{−1,+1}, asks for a margin rather than a probability. Neither choice is a universal upgrade; the target, imbalance, and evaluation metric determine what is appropriate.

Full-batch gradient descent averages over the whole training set. A minibatch estimates that gradient with fewer examples. Uniform sampling gives an unbiased estimate of the empirical data gradient, but individual updates are noisy; batch-dependent operations can complicate this picture. Noise can help exploration, but it does not guarantee escape from every bad region. Batch size also changes update frequency, memory use, and how a learning-rate schedule should be interpreted.

Momentum remembers a direction. One consistent convention is vt=βvt−1+gt, followed by θt=θt−1−ηvt. Persistent gradient components accumulate; alternating components partly cancel. Nesterov momentum evaluates the gradient at a look-ahead point, θt−1−ηβvt−1, before completing the update. Different libraries use algebraically related conventions, so the velocity definition must accompany the formula.

Adaptive methods keep a different step scale for each coordinate. AdaGrad accumulates squared gradients, st=st−1+gt², and divides the gradient by √st+ε, elementwise. Rarely active coordinates can keep relatively large effective rates, useful for some sparse problems. Because the accumulator never forgets, rates can shrink excessively during long training. RMSProp replaces the cumulative sum with an exponential average, st=βst−1+(1−β)gt².

Adam combines first- and second-moment estimates. With m₀=v₀=0 and gradient at θt−1:

mt = β₁mt−1 + (1−β₁)gtvt = β₂vt−1 + (1−β₂)gt²m̂t = mt/(1−β₁t),   v̂t = vt/(1−β₂t)θt = θt−1 − ηm̂t/(√v̂t+ε)Squares, square roots, and division are elementwise. Bias correction compensates for zero-initialized moving averages.

These methods provide diagonal preconditioning based on gradient history. Squared gradients are not the full Hessian; adaptive scaling cannot generally remove rotated correlations between parameters, and it does not automatically prevent divergence. Learning rate, data scaling, schedule, and generalization still require attention. The original Adam algorithm is the reference for the moment and bias-correction equations here.

Regularization changes which solutions are preferred. An L2 term λ‖θ‖₂²/2 adds λθ to the gradient. Under plain SGD, this is equivalent to multiplying weights by 1−ηλ each update. Under adaptive scaling, adding an L2 gradient and applying decoupled weight decay are generally different operations. L1 has a corner at zero and can encourage exact sparsity, especially with proximal updates; ordinary gradient steps alone need not produce exact zeros.

Dropout instead perturbs the computation during training. In inverted dropout, each activation is multiplied by an independent mask m/(1−p), with m∼Bernoulli(1−p). The expectation is preserved. At evaluation time the masks are removed, and no extra scaling is needed under this convention. Batch normalization, when present, typically uses minibatch statistics in training and stored statistics in evaluation. That is why both the model’s mode and gradient-recording mode matter.

Finally, optimization success is not the same as useful learning. Track training and validation losses, inspect the task metric, and save a checkpoint selected using validation evidence. Falling training loss with rising validation loss is a reason to revisit capacity, regularization, data, or stopping time. The optimizer can only improve the objective we supplied; it cannot decide whether the objective or evaluation reflects the intended task.

09 · Let architecture express spatial assumptions

Convolution is a sparse matrix with shared entries

Book: chapter 10, pp. 343–384.

A fully connected layer treats every input coordinate as unrelated to its neighbors and learns a separate weight for every connection. Images have spatial structure: a useful edge pattern can appear in many places. Convolution encodes two assumptions. A feature can be detected from a local neighborhood, and the same detector should be reused across locations. Local connectivity reduces connections; weight sharing reduces independently learned parameters.

Most neural-network libraries implement cross-correlation, although the operation is called convolution: the kernel is not reversed. For a one-dimensional signal, a valid stride-one operation is yi=∑j=0k−1wjxi+j+b. A kernel [1,−1] takes adjacent differences; [½,½] averages neighbors. Learning chooses the kernel values rather than requiring us to design every detector.

For 2D input [B,Cin,H,W], a standard kernel has shape [Cout,Cin,kH,kW]. Each output channel sums across all input channels and spatial kernel positions. The parameter count is Cout(CinkHkW+1) with a bias per output channel. A 3×3 layer from 3 to 16 channels has 448 parameters, independent of image dimensions. The same locality and sharing can therefore process many positions without allocating a separate detector to each one.

Along one spatial axis, input size N, symmetric padding p, kernel size k, stride s, and dilation d give:

Nout = ⌊(N+2p−d(k−1)−1)/s⌋ + 1Dilation spaces kernel taps apart, making the effective width d(k−1)+1. Apply the formula independently to height and width.

For N = 7, k = 3, p = 1, s = 2, and d = 1, the output has length 4. A unit-stride convolution is translation equivariant away from boundary effects: translating the input translates the output. This is different from invariance, where output would remain unchanged. Padding and finite image boundaries qualify exact equivariance; stride greater than one generally preserves it only for compatible shifts. Pooling can introduce some local tolerance while also losing precise position and introducing aliasing.

Stacked small kernels expand the receptive field. Two 3×3 stride-one layers can depend on a 5×5 patch; a third expands it to 7×7. Nonlinearities between them add expressive power. Pooling summarizes a neighborhood with a maximum or average and usually has no learned weights. Three-dimensional convolution extends the kernel across an additional spatial or temporal axis: for video, a kernel can combine nearby frames as well as neighboring pixels. Its input and kernel axes must keep time distinct from channels.

Flatten the spatial arrays and a convolution becomes a structured matrix multiplication y=Ax, with repeated kernel entries and many zeros. Its transpose maps output-space vectors back to input-space vectors and satisfies ⟨Ax,y⟩=⟨x,Aᵀy⟩. This adjoint is the basis of transposed convolution and the backward gradient with respect to the input.

Transposed convolution is not an inverse. Increasing output size does not recover information destroyed by downsampling or a nullspace. With stride s, one common interpretation inserts zeros between incoming values, then accumulates weighted overlaps. Its one-axis output size is (Nin−1)s−2p+d(k−1)+o+1, with output-padding parameter o resolving some shape ambiguities. The exact adjoint requires matching the original operator’s padding and input/output shape choices. A separately learned decoder need not share the encoder’s weights at all.

These distinctions explain both the efficiency and the limits of convolution. It imposes a useful pattern of connections, but larger objects, varying scales, and long dependency paths still require architectural choices above the kernel level.

10 · Architecture is an argument about computation

From image classification to finding objects

Book: chapter 11, pp. 385–437.

Convolution supplies a building block, not a complete visual system. An architecture decides how spatial scale, channel width, nonlinear computation, and information paths change with depth. The progression from LeNet through VGG, Inception, and ResNet is useful because each addresses a different structural problem. Memorizing their names misses the transferable design choices.

LeNet alternates local feature extraction with spatial reduction, then uses dense layers to make a global decision. Nearby evidence is combined first; later units integrate larger portions of the image. This separates the job of finding reusable local patterns from the job of recognizing the whole input. It also illustrates the tradeoff of downsampling: cheaper computation and broader context in exchange for precise spatial detail.

VGG makes depth systematic by stacking small 3×3 kernels. Two such layers have a 5×5 receptive field and an extra intervening nonlinearity. With C input, hidden, and output channels, they use roughly 18C² kernel weights instead of 25C² for one 5×5 layer. This comparison assumes constant width and ignores biases; changing channels changes the count. The larger lesson is that a large spatial operation can be factorized into smaller learned operations.

Inception explores several receptive-field sizes in parallel and concatenates the resulting channels. A small pattern and a large pattern can both contribute to the next representation. A 1×1 convolution mixes channels at each location without mixing locations. Using it to reduce channel width before an expensive spatial convolution makes the parallel design affordable; it is a learned bottleneck, not merely a reshaping operation.

ResNet changes the path through depth. A block computes y=x+F(x), so the branch learns a residual correction to an identity path. If dimensions change, a projection P can give y=Px+F(x). For an identity skip, the backward relationship is ∂J/∂x=(I+JF)ᵀ∂J/∂y. The direct term gives a short route for information and gradients. It does not guarantee that gradients cannot vanish: terms can cancel and other operations still matter. It makes learning near-identity transformations easier and permits useful computations at many effective path lengths.

Classification assumes an image-level answer. Object detection adds a variable number of objects, locations, and classes. A brute-force detector could classify every possible crop, but the overlap would waste computation. R-CNN proposed regions and ran a CNN on each crop. Fast R-CNN shared a convolutional feature map across regions. Faster R-CNN also learned to propose the regions, reusing that shared representation.

In Faster R-CNN, the backbone first maps the image to a spatial feature tensor. A region proposal network, or RPN, examines feature-map locations. At each location it considers A predefined anchor boxes with different sizes or aspect ratios. Its outputs include objectness scores and four regression offsets per anchor. Objectness asks whether an object is present, independently of its eventual category. Anchors are reference boxes; regressed proposals are candidate boxes after adjustment.

Training needs a rule for matching anchors to ground-truth boxes. Intersection over union is IoU(B,G)=area(B∩G)/area(B∪G). Matching rules label sufficiently overlapping anchors positive, low-overlap anchors negative, and often ignore an intermediate range. Exact thresholds and sampling ratios are implementation choices. With center coordinates (x,y), width w, and height h, targets relative to anchor a commonly use:

tₓ = (x*−xₐ)/wₐ,   tᵧ = (y*−yₐ)/hₐtw = log(w*/wₐ),   th = log(h*/hₐ)Decoding reverses the parameterization: x = xₐ+wₐtₓ and w = wₐ exp(tw), with analogous formulas for y and h.

RoI pooling divides each proposal’s feature-map region into a fixed grid and pools within bins. This gives a common-sized representation despite variable box dimensions, but quantization loses some alignment. The detection head produces category scores, including background, plus another box adjustment. Non-maximum suppression greedily retains high-scoring boxes and suppresses sufficiently overlapping alternatives. It is a selection heuristic; crowded scenes can make the overlap threshold consequential.

The training objective combines RPN objectness classification, RPN box regression, final category classification, and final box regression. Regression terms apply only to positive matched examples, commonly with a smooth-L1 penalty that is quadratic near zero and linear farther away. Loss weights and normalizations balance the tasks. Shared backbone parameters receive gradient contributions from both heads; this does not make proposal ranking or NMS differentiable.

Other detection paradigms organize the same problem differently. One-stage detectors predict classes and boxes directly from dense locations, avoiding a separate proposal-classification stage. Anchor-free designs predict centers or other geometric references instead of enumerating anchor templates. The useful comparison is the allocation of computation, supervision, and geometric assumptions, rather than a universal claim that one family is always better. The book’s vision examples show how mathematical pieces become systems once their shapes and responsibilities are made explicit.

11 · The shape of data, the strength of evidence

Low-dimensional structure does not remove uncertainty

Book: chapter 12, pp. 438–446; chapter 13, pp. 447–467.

We have treated images as points in a high-dimensional space, yet most arbitrary pixel arrays are unlike natural images. Meaningful data often concentrates near a lower-dimensional structure. A manifold is a mathematical model for a space that looks locally like an open subset of ℝd. The integer d is its intrinsic dimension, which can be much smaller than the number of coordinates used to describe it. A circle is one-dimensional even when embedded in a plane.

The standard topological definition also requires the Hausdorff and second-countability properties, which prevent certain pathological spaces. Local Euclidean structure alone does not supply derivatives: a smooth manifold additionally has compatible smooth coordinate charts. Nor is every continuous curve a manifold; a figure-eight crossing fails to look locally like an interval at its intersection. Real datasets are finite and noisy, so the manifold hypothesis is a modeling guide, not a literal claim that every observation sits exactly on a perfect surface.

A homeomorphism is a bijection that is continuous in both directions. It preserves topology, including connectedness and holes. A circle is locally line-like but cannot be continuously flattened into one interval with a continuous inverse while preserving all points. Any angular coordinate must have a cut or use multiple charts. This is why global statements about “unrolling” a manifold need more care than a local picture suggests.

Some neural layers are homeomorphisms onto their images: an invertible square affine map followed by a componentwise sigmoid is one example, with image inside (0,1)d. Generic layers are not. ReLU merges many negative inputs into the same zero output; pooling and rank-deficient maps lose distinctions. A taller full-column-rank affine map can embed a space into a larger one, but changing dimensions does not automatically preserve or destroy all relevant information on a particular data manifold. Learned representations may deliberately merge inputs that should share a label.

Geometry alone also does not tell us how certain a prediction should be. MLE and MAP choose point estimates of parameters. Full Bayesian inference instead keeps p(θ|D) and averages predictions over it:

p(y*|x*,D) = ∫ p(y*|x*,θ) p(θ|D) dθ

A Gaussian example makes the distinction exact. Suppose observations satisfy xi|μ ∼ 𝒩(μ,σ²), independently, with known σ². Put prior μ∼𝒩(μ₀,τ₀²). Completing the square in likelihood times prior gives another Gaussian:

τn² = (1/τ₀² + n/σ²)−1μn = τn²(μ₀/τ₀² + n x̄/σ²)μ|D ∼ 𝒩(μn,τn²)Precisions, the reciprocals of variances, add. The mean is a precision-weighted average of prior mean and sample mean.

Take μ₀ = 0, τ₀² = 4, σ² = 4, n = 4, and sample mean x̄ = 3. The prior precision is 0.25, the data precision is 1, and the posterior variance is 1/1.25=0.8. The posterior mean is 0.8×3=2.4. MLE would return 3. Bayesian inference retains both the shifted mean and uncertainty about it.

Integrating over μ gives the predictive distribution x*|D∼𝒩(μn,σ²+τn²). Its variance separates irreducible observation noise from uncertainty about the mean. As n increases, the latter shrinks, while σ² remains. This conclusion relies on the assumed sampling model. Repeated biased observations can make a misspecified model highly confident in the wrong answer.

The chapter’s other conjugate families follow the same pattern of algebraic closure. For unknown univariate precision λ=1/σ² with known mean, use a gamma prior. Under the shape–rate convention, its density is proportional to λa−1e−bλ; the posterior has an=a₀+n/2 and bn=b₀+½∑(xi−μ)². State rate versus scale explicitly: confusing them reverses the interpretation of b.

When both mean and precision are unknown, a normal–gamma prior uses μ|λ∼𝒩(μ₀,(κ₀λ)−1) together with a gamma distribution over λ. Multivariate unknown means with known covariance have Gaussian conjugate priors. Unknown precision matrices use a Wishart family, a distribution over positive-definite matrices; jointly unknown mean and precision lead to a normal–Wishart construction. These families illustrate tractable posterior reasoning, not a requirement that neural-network posteriors have closed forms. For more complex latent models we need an approximation that can itself be learned.

12 · Bring the pieces together

A variational autoencoder learns a space it can sample

Book: chapter 14, pp. 468–496; chapter 6, pp. 215–216.

An autoencoder learns an encoder z=eϕ(x) and decoder x̂=dθ(z), trained to reconstruct the input through a bottleneck. Labels are unnecessary because the input supplies the target. A useful low-dimensional code must retain information needed for reconstruction, but reconstruction alone does not guarantee a semantic or disentangled representation. A highly flexible network may also memorize the training examples.

Under specific conditions, this returns us to PCA. A linear encoder and decoder with a k-dimensional bottleneck, centered data, squared reconstruction error, and a global optimum span a principal k-dimensional subspace. The actual latent coordinates need not equal the principal-component coordinates: invertible changes of basis inside the bottleneck can leave reconstruction unchanged. Nonlinear activations, other losses, or architectural constraints change the result. The connection is about the optimal reconstruction subspace, not every trained autoencoder.

A deterministic autoencoder can reconstruct well while leaving large unused holes in latent space. The training objective only constrains decoder behavior at codes produced by the encoder. Sampling an arbitrary z need not produce a plausible input, and interpolation can pass through regions the decoder scarcely learned. Reconstruction distance also does not automatically give a calibrated probability that an input belongs to a class or is anomalous.

There are two related meanings of generative modeling. A discriminative classifier directly models p(y|x). A generative classifier models class priors p(y) and class-conditional observations p(x|y), then obtains p(y|x) by Bayes’ rule. Both can produce probabilistic predictions, and either can overfit. A latent generative model goes further by describing how an observation could arise from an unobserved code, whether or not class labels exist.

A generative model makes the missing assumption explicit. Choose a latent prior p(z), often 𝒩(0,I), and a decoder likelihood pθ(x|z). Together they define the joint pθ(x,z)=p(z)pθ(x|z). Generation is well specified: draw z from the prior, then draw x from the decoder. Inferring a code for an observed input instead requires the posterior:

pθ(z|x) = pθ(x|z)p(z) / pθ(x),   pθ(x) = ∫ pθ(x|z)p(z) dz

For a nonlinear decoder, that evidence integral is generally intractable to evaluate exactly. The issue is integration over latent configurations, not a universal quadratic cost in dataset size. A variational autoencoder introduces a tractable approximation qϕ(z|x), whose parameters are produced by an encoder network. One encoder is reused across inputs: this is amortized inference.

The training objective follows from inserting q into the marginal likelihood. Assuming compatible supports, write log pθ(x) = log Eq[pθ(x,z)/qϕ(z|x)]. Jensen’s inequality moves the logarithm inside the expectation to produce a lower bound:

log pθ(x) ≥ Eq[log pθ(x,z) − log qϕ(z|x)]ℒ(θ,ϕ;x) = Eq[log pθ(x|z)] − DKL(qϕ(z|x) ‖ p(z))

This is the evidence lower bound, or ELBO. The first term rewards reconstructing the observed input under the decoder likelihood. The second penalizes the approximate posterior’s divergence from the prior. An exact identity explains the bound’s gap:

log pθ(x) = ℒ(θ,ϕ;x) + DKL(qϕ(z|x) ‖ pθ(z|x))

At fixed θ, maximizing the bound over ϕ improves the posterior approximation. During joint training, θ also changes, so the evidence is not constant. The KL to the prior in the objective and the KL to the true posterior in the gap are different quantities. Confusing them obscures why this objective simultaneously learns a generative model and an inference procedure.

For a diagonal Gaussian encoder, qϕ=𝒩(μ,diag(σ²)), the prior penalty has a closed form:

DKL(qϕ‖𝒩(0,I)) = ½∑j=1k(μj² + σj² − 1 − log σj²)

It is minimized when every μ is zero and every variance is one. It does not put high-dimensional standard-normal samples mostly inside a radius-one ball: their squared radius has expectation k, so the characteristic radius grows like √k. Nor does the regularizer guarantee a perfectly smooth semantic space. It encourages a relationship between encoded distributions and the prior; the learned decoder and reconstruction term determine what that relationship means.

We still need gradients through the sampled code. Draw parameter-independent noise ε∼𝒩(0,I), then set z=μ+σ⊙ε. For fixed ε, this is differentiable with ∂zj/∂μj=1 and ∂zj/∂σj=εj. The reparameterization trick gives a Monte Carlo gradient estimate by moving the learnable parameters out of the random draw itself. For full covariance Σ, use a factor L with LLᵀ=Σ and z=μ+Lε; multiplying by Σ would give the wrong covariance.

In code, encoders usually output log variance l=log σ². Then σ=exp(l/2), which enforces positivity. The loss minimized per example is negative ELBO: a sampled reconstruction negative log-likelihood plus the analytic KL. A Gaussian decoder with fixed variance gives a scaled squared-error term; a Bernoulli decoder gives binary cross entropy for genuinely binary observations. A bounded continuous pixel is not automatically a Bernoulli variable. The likelihood should match the data interpretation, and reconstruction/KL reductions must have consistent scaling across pixels, latent dimensions, and minibatches.

A strong decoder can ignore the latent code, yielding posterior collapse: the approximate posterior stays close to the prior while carrying little information about the input. Conversely, weak regularization can permit a useful reconstruction code whose prior samples decode poorly. The original VAE formulation makes this a coupled modeling and inference problem rather than a guarantee of useful latent semantics.

We have returned to the same chain with which we began. Linear algebra supplies representations and approximation error. Probability says what observations and hidden causes mean. Calculus turns a loss into parameter sensitivities. Architecture makes some computations economical and some patterns easy to learn. The VAE needs all four at once: a learned coordinate system, a probabilistic objective, a differentiable sampling path, and an encoder–decoder computation that can actually be trained. Understanding those connections is more durable than memorizing a catalog of layers.

Keep beside the equations

Notation, source map, and precision checks

The same symbols recur because the same operations recur. An individual input is a column; a dataset stores inputs in rows. Means and losses are defined with explicit normalization. Normal-distribution notation uses variance as its second argument, while σ itself denotes standard deviation. The distinction is easy to lose in code that emits log variance.

SymbolMeaning and shape
x, yOne input and target; x is a d-dimensional column.
X, n, dn × d data matrix; one observation per row.
W, bm × d layer weights and m-dimensional bias.
θ, ϕModel parameters; ϕ distinguishes an encoder when needed.
J, ℓ, ηTraining objective, per-example loss, learning rate.
μ, σ², ΣMean, scalar variance, covariance matrix.
⊙, ᵀ, ⁺Elementwise product, transpose, Moore–Penrose pseudoinverse.
p, q, EProbability model, comparison/approximate distribution, expectation.

Read an unfamiliar formula by checking three things. First ask what each axis or variable represents. Then check dimensions and support: which products exist, which distributions can assign positive mass, and which logarithms are finite? Finally ask what is held fixed. A derivative at fixed noise, a likelihood at fixed data, and a posterior at fixed model parameters are different operations even when they share symbols.
